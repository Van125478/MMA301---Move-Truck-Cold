# Coldi Mobile — Design System (UI UX Pro Max)

**Product:** Logistics / B2B marketplace (cold chain)  
**Pattern:** Feature showcase + trust  
**Style:** Minimal & Swiss, flat surfaces, no AI gradients  
**Stack:** React Native + Expo, Inter  

## Color
- Primary / brand: `#1D428A`
- Background: `#F8FAFC`
- Surface: `#FFFFFF`
- Ink: `#0F172A`
- Muted: `#64748B`
- Line: `#E2E8F0`
- Success (in transit): `#15803D` on `#DCFCE7`

## Type (mobile)
- Screen title: 26/34 Bold
- Card route (hero line): 17/24 Semibold, **1 line**
- Body: 15/22 Regular
- Meta / label: 13/18 Medium
- Price: 20/26 Bold, primary color

## Spacing (8px rhythm)
8 · 12 · 16 · 24 · 32

## Card (marketplace listing)
1. Photo full-bleed top (180px showcase / 128px list)
2. Row: order code + status pill (nowrap)
3. **Cargo title** — Bold 17/24 ink, max 2 lines (không xám chìm)
4. **Route one line:** `{pickup} → {delivery}` (Semibold 15, ellipsis — không chấm xanh/đỏ)
5. One vehicle chip (nowrap)
6. Footer 2 columns: **Giờ bốc** | **Giá cước** (fixed 50/50)

## Anti-patterns (avoid)
- Emoji as icons
- Vertical route with arrow-down
- Gray-on-gray body text
- Clipped badges without ellipsis
- More than 3 visual levels in one card block
